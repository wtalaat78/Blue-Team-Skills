# Blue Team Skills

Enterprise Blue Team skills, runbooks, and playbooks for defensive security, authorized application security testing, secure code review, posture scoring, and SOC integration.

## Available Skills & Shortcuts

- **`/appsec`** or **[`internal-appsec-testing`](file:///d:/Techwaves-egy/Blue-Team-Skills/skills/internal-appsec-testing/SKILL.md)**: 
  - **Pre-Fix Assessment Reporting**: Mandatory pre-remediation security report with domain scoring before changing code.
  - **10-Point Security Scorecard**: Standardized scoring (`0.0 – 10.0`) across 10 security testing categories with overall posture calculation.
  - **Comprehensive Vulnerability Dockets**: Evidence, CVSS v3.1, root-cause analysis, and production-ready defensive remediation.
  - **SOC Integration**: Tailored SIEM alert rules (Sigma, KQL, Splunk) for every critical/high finding.
  - **Post-Fix Verification**: Regression retesting and Post-Fix Score Delta ($\Delta\text{Score}$).
