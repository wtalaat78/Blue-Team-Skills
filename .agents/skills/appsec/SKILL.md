# /appsec Shortcut

Activates the **`internal-appsec-testing`** skill.

When the user runs `/appsec` or `/internal-appsec-testing`:
1. Load and execute the instructions in [`internal-appsec-testing`](../internal-appsec-testing/SKILL.md).
2. Establish authorization boundary, identify testing mode (Black Box, Gray Box, White Box), and apply the 43-step enterprise Blue Team AppSec framework.
